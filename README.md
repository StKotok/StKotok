### How I write code with AI

Claude Code is my main tool, with subagents, skills, hooks and my own MCP servers. A stronger model plans each task and checks the result; a faster one writes the code from a brief with acceptance criteria. I own the architecture, the hard parts and the final review: generated code is merged only after type checks, tests and an architecture review. Before an irreversible step – a migration, a deployment, an access change – Gemini, Grok and ChatGPT review the plan in turn; their advice can stop the step, but only a measurement lets it go ahead.
